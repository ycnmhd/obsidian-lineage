# Fixes and extensions
The original plugin is not actively maintained anymore so I forked it in order to continue it. Originally this started just as a fix for lineage block links, but I extended it greatly because I just love this plugin and write everything in it. I added and fixed:

- Fixed search
  - Highlights the text you searched in the respective cards
- Fixed wrong paragraph handling, works now the same way as vanilla Obsidian
- Clicking on blocklinks actually takes you to the cards you referenced

## Pinned cards and Organization
- Local and global categories
  - You can categorize pinned cards into self-definable categories
  - New global category view: Global categories show cards from multiple different documents (fully editable)
  - Reveal in sidebar option
- Zen Mode
  - Hides *every* UI element not necessary for writing to allow maximum focus

If you have any more suggestions (or want to contribute) please do! 

All further Obsidian plugins in my account are forked to create compatibility with lineage. 
# Lineage
Lineage is an Obsidian plugin that allows you to edit markdown files in a [gingko-like](https://gingkowriter.com/) interface.

![](https://raw.githubusercontent.com/ycnmhd/obsidian-lineage/docs/docs/media/screenshot.png)

## Usage
To open a file, use the ribbon icon, the file context menu, or the command palette.
To export a file, use the view context menu.
